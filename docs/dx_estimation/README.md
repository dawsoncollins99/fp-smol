# $D_x$ estimation: write-ups and talk

| Folder | Document |
|---|---|
| `writeup_noise_free/` | **Estimating How Turbulence Spreads Out Cloud Droplet Sizes.** Steady state, exact data: the equation, the numerical scheme, the loss, the adjoint gradient, and the optimizer, written for readers without a cloud-physics background. |
| `writeup_noisy/` | **Estimating $D_x$ from Noisy Droplet Counts.** Sampling noise and the Poisson model, the Poisson deviance, single-sample error bars from the loss curvature, Monte Carlo checks, and detection limits. |
| `talk/` | **Estimating turbulent broadening of cloud droplet size distributions.** Talk for BYU and the MTU group (October 2026), including questions for the MTU physicists. |

Each folder contains the LaTeX source, the compiled PDF, and a `figures/` folder.

## Rebuilding

The figures are generated by the scripts in
[`examples/dx_estimation/`](../../examples/dx_estimation/) (see its README).
To compile a document:

```bash
cd docs/dx_estimation/talk
latexmk -pdf Dx_estimation_talk.tex
```

The talk uses the Beamer `metropolis` theme; the write-ups use standard packages
(amsmath, tcolorbox, tikz, booktabs).
